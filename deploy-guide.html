InterviewAI
部署指南

三步，把 AI 面试模拟系统跑起来

基于 LLM + Agent 的面试模拟系统，Docker 一键部署，本地即可访问。

前置条件 已安装并启动 Docker Desktop（或本机 Docker）
  1. 1

    下载代码

    把 GitHub 仓库复制到本地。

    git clone https://github.com/xioa-cheng/InterviewAI-Agent.git
cd InterviewAI-Agent
  2. 2

    配置密钥

    复制配置模板，然后编辑 .env，填入 DEEPSEEK_API_KEY 和 SECRET_KEY。

    # Windows
copy .env.example .env
# Mac / Linux
cp .env.example .env
  3. 3

    一键启动

    构建并启动全部服务（后端 + 前端 + 数据库 + Redis）。

    docker compose up -d --build

启动后访问

网页界面
http://localhost:5173
后端接口文档
http://localhost:8000/docs

注意事项

  • ·API Key 自己填 —— DeepSeek 密钥不随代码公开，谁用谁填，保证安全。
  • ·首次打开先注册账号 —— 注册并登录后即可开始面试。
  • ·管理员 —— 在 .env 里配置 ADMIN_EMAIL，该邮箱注册即成为管理员。
